# Power BI Dashboard

Open `dashboard.pbix` in Power BI Desktop.

The preview image in this directory summarizes the supplied report layout. The screenshot shows KPI cards for Total Sales, Total Profit, Total Orders, and Average Order Value; sales trends and breakdowns by payment mode, order status, product, and category; profit by category; a geographic visual; and Month, City, and Payment Mode filters.

Refresh the report and validate data sources, measures, and filter behavior in Power BI Desktop before relying on the displayed numbers for business decisions.
