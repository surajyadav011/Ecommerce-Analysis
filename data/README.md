# Data

`sample_ecommerce.csv` is a small, PII-free sample for exploring the project schema. It is not the full original dataset.

The original workbook and cleaned full CSV contain customer-related fields. Before publishing a full dataset, use anonymized versions and check the source-data license. The uploaded original files are available in the local project handoff bundle; binary workbook upload to this repository is still pending.

The cleaning workflow derives `Sales`, `Net_Amount`, `Profit`, `Month`, `Year`, and `Weekday`. `Profit` is estimated using an assumed 20% margin, not actual cost accounting.
